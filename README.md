## 🛸 О Проекте

**AndromedaAI** — это интеллектуальная графическая экосистема для автоматизации процессов разведки (Reconnaissance) и пентеста.

В отличие от классических ИИ-чатботов, AndromedaAI использует концепцию **Micro-Stepping (микро-шагов)**. Проект разбивает аналитические задачи на микроскопические шаги, пропускает их через легковесные модели и сохраняет каждый шаг в локальную базу данных.

## 🎛️ Функциональные Модули

### 🪐 1. Модуль Анонимизации (Network Anonymizer)
* **Tor + SOCKS5 / Proxychains Integration**: Проверка прямого и прокси-IP адреса.
* **IP-Rotation Engine**: Смена выходной ноды Tor (`NEWNYM` сигнал на порт 9051) с мгновенной проверкой нового IP.

### 🎯 2. Разведка (Reconnaissance Module)
* **Nmap Scanner**: Фоновый запуск быстрого сканирования портов (`nmap -sV -F`) с поддержкой Proxychains.
* **Хакерский Терминал**: Потоковый вывод результатов сканирования в реальном времени.
* **ИИ-Микроанализ**: Автоматическое выделение открытых сервисов (HTTP, SSH и др.) и рекомендация векторов атаки.

### ⚡ 3. Дашборд Управления (Dashboard Control)
* **Управление Целями**: Безопасный ввод IP/доменов (`INSERT OR IGNORE`) и их динамическое отображение.
